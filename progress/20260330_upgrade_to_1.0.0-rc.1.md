# Upgrade to OpenChoreo v1.0.0-rc.1

## What Changed

Major restructuring of the Flux setup to align with upstream v1.0.0-rc.1 helm charts.

### Architecture Changes
1. **Thunder extracted to separate namespace/chart** - Thunder IDP is no longer embedded in the control-plane chart. Now runs in its own `thunder` namespace as `oci://ghcr.io/asgardeo/helm-charts/thunder:0.28.0` with full bootstrap scripts.

2. **Build Plane → Workflow Plane** - `openchoreo-build-plane` chart/namespace renamed to `openchoreo-workflow-plane`. Old build-plane directory deleted, new workflow-plane created.

3. **kgateway v2.2.1 + controller** - kgateway-crds bumped from v2.1.1 to v2.2.1 and moved to `openchoreo-control-plane` namespace. New `kgateway` controller HelmRelease added with `KGW_ENABLE_GATEWAY_API_EXPERIMENTAL_FEATURES=true`.

4. **OpenBao standalone** - OpenBao deployed as infrastructure component in its own `openbao` namespace (was embedded in build-plane). Includes init Job for auth/policy setup and dev secret seeding. ClusterSecretStore `default` created for all planes.

5. **Plane CR API changes** - `DataPlane` → `ClusterDataPlane`, `BuildPlane` → `ClusterWorkflowPlane`, `ObservabilityPlane` → `ClusterObservabilityPlane`. Gateway spec restructured.

### Values Changes
- **Control Plane**: New structure with `openchoreoApi`, `backstage`, explicit `gateway.httpPort/httpsPort`, `tls.enabled: false`. Removed `global.baseDomain`, `thunder` section.
- **Data Plane**: Ports changed from 9080/9443 to 19080/19443. Added `fluent-bit` env vars. Removed `selfSignedIssuer`, `gatewayController`.
- **Observability Plane**: New `observer.http.hostnames`, `rca` section, `security.oidc.authServerBaseUrl`. Thunder URLs now point to `thunder` namespace.
- **Workflow Plane**: Argo servicePort changed to 10081. Registry port changed to 10082. OpenBao removed.

### New Resources
- `apps/thunder/` - Thunder HelmRelease + values with bootstrap scripts
- `apps/openchoreo-control-plane/backstage-secrets.yaml` - Static dev secrets
- `apps/openchoreo-control-plane/coredns-custom.yaml` - DNS rewrite for openchoreovm.test
- `apps/openchoreo-observability-plane/external-secrets.yaml` - OpenSearch + Observer secrets from OpenBao
- `infrastructure/kgateway/helmrelease.yaml` - kgateway controller
- `infrastructure/openbao/` - OpenBao HelmRelease + init Job + ClusterSecretStore

### k3d Config Changes
Port mappings updated to match new chart defaults (direct port mapping instead of remapped).

## Deployment Notes

### Prerequisites before deploying
1. **Recreate the k3d cluster** - Port mappings changed significantly. The old cluster must be deleted and recreated with the new k3d-config.yaml.
2. **Nginx config update** - The VM's nginx reverse proxy config may need updating since k3d internal ports changed (e.g., CP gateway now on 8080 instead of 80).

### Post-deployment
1. The OpenBao init Job should run automatically and configure auth + seed dev secrets.
2. Verify cluster-gateway-ca Certificate is issued and ConfigMap is created.
3. Verify all plane agents connect successfully.
